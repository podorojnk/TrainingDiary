# TrainingDiary
# Модуль 1: Справочник упражнений
  - Как пользователь, я хочу просматривать список упражнений и группировать их по мышечным группам (грудь, спина, ноги и т.д.), чтобы быстро находить нужные движения. Также, , я хочу добавлять кастомные упражнения, чтобы вносить в дневник нестандартные движения.

  - Файлы: Exercise / CatalogService
# Модуль 2: Журнал тренировочной сессии
   - Как пользователь, я хочу создавать новую тренировку (дата, название) и фиксировать сет внутри упражнения (номер подхода, рабочий вес, количество повторений), чтобы точно отслеживать нагрузку.

   - Файлы: Workout / SetEntry
# Модуль 3: Анализ прогресса и Рекордов
  - Как пользователь, я хочу видеть свой личный рекорд (максимальный вес в конкретном упражнении) и суммарный тоннаж (общий поднятый вес за тренировку), чтобы отслеживать рост рабочих весов от даты к дате.

  - Файлы: ProgressAnalytics
# Модуль 4: Профиль пользователя и Сохранение
  - Как пользователь, я хочу, чтобы мои текущие параметры (вес, цель) и вся история тренировок сохранялись в локальном хранилище, чтобы не терять данные при перезапуске приложения.

  - Файлы: UserProfile / WorkoutStorage
